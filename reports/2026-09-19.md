## New today

- ✅ **[goraven](https://github.com/8treenet/goraven)** (agent-infra) — GoRaven is a self-hosted AI agent platform written in Go/React that lets team members create isolated workspaces where agents can read/write files, execute shell commands, call APIs, and use RAG-based knowledge retrieval.
- ✅ **[Chisle](https://github.com/JayPokale/Chisle)** (agent-infra) — Chisle injects a session-level ruleset and a per-tool-call compression pipeline (PostToolUse for Claude/Pi) to cut AI coding agent token usage across three axes: terse prose, YAGNI-first code, and tool-output scrubbing. It auto-configures for 11 agents via a zero-dependency CLI, publishes raw benchmark runs including its own failures, and is actively maintained.
- ✅ **[Interceptor](https://github.com/Hacker-Valley-Media/Interceptor)** (browser-automation) — Interceptor provides a CLI and MCP server that connects AI agents to a user's existing signed-in browser (via extension), native macOS apps (via accessibility/Apple Events), and physical iPhones (via WebKit inspection). It supports background automation, structured UI reads, network inspection, rich-editor interaction, and record/replay workflows.
- ✅ **[rish-app](https://github.com/ZSeven-W/rish-app)** (memory-context) — Rish is a mobile app that lets you run AI agent workflows locally on iOS or Android, choose from several LLMs, and execute tools with approval steps without needing a separate computer.
- ✅ **[galadriel-public](https://github.com/avasol/galadriel-public)** (data-research) — Galadriel is a self‑hosted, persistent AI agent framework that stores verbatim memories locally, lets you swap LLMs without losing context, and lets the agent edit its own code and UI via Docker or Python.
- ✅ **[agentscope-go](https://github.com/agentscope-ai/agentscope-go)** (agent-infra) — A Go library for building LLM-powered agents with tool calling, multi-agent workflows, and memory; provides concrete APIs, multiple model provider adapters, and runnable examples.
- ✅ **[pi-rust](https://github.com/bigfish1913/pi-rust)** (content-video) — The repo provides a Rust-native, library-first runtime and CLI for building composable LLM coding agents with pluggable providers, tools, sessions, and a stable plugin ABI.
- ✅ **[AgentLabKit](https://github.com/hhtttttiger/AgentLabKit)** (trading) — AgentLabKit is a Python/React platform for building, running, observing, and evaluating AI agents. It provides a reusable agent runtime, provider‑neutral LLM gateway, RAG engine, guardrails, workflows, long‑term memory, evaluation tooling, cost analysis, and both web and desktop clients.
- ✅ **[claude-plugins](https://github.com/erikdarlingdata/claude-plugins)** (dev-tools) — A collection of plugins for Claude Code, GitHub Copilot CLI, and pi that teach LLMs to analyze SQL Server execution plans (.sqlplan files) with correct self-time attribution and cardinality normalization, plus pi-only session resume and subagent watchdog extensions.
- ✅ **[Agnostic-AI](https://github.com/ucsandman/Agnostic-AI)** (dev-tools) — Agnostic AI captures your AI coding configuration (rules, hooks, skills, subagents, commands, MCP servers) from one client like Claude Code and ports it identically to 20+ other clients (Codex, Gemini CLI, Cursor, etc.) via three commands: sync, port, and doctor. It uses a client-neutral bundle, shimmed hooks, and a private overlay for user-specific data.
- ✅ **[embassy](https://github.com/YuanpingSong/embassy)** (agent-infra) — Embassy is a local broker that lets Claude Code and Codex CLI agents exchange messages by alias on one Mac or across Macs over SSH. It discovers Codex agents, wakes Claude sessions through their native interfaces, and returns transport receipts rather than claims of successful comprehension.
- ✅ **[agentplaybooks](https://github.com/matebenyovszky/agentplaybooks)** (agent-infra) — AgentPlaybooks provides a portable JSON-based playbook format that stores agent personas, skills, MCP servers, memory, and encrypted secrets, with a CLI and plugins to sync the playbook to multiple AI agent platforms (Claude Code, Cursor, ChatGPT/Codex, etc.) and a self-hostable Next.js + Supabase + Cloudflare Workers stack.
