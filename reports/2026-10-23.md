## Flagged as hype

- **scale** — The README describes a concrete, reproducible system with specific npm packages, installation steps, and component types. However, the project is explicitly labeled as "open beta" in the README, indicating it is still in early-stage development. While the core functionality is real and well-documented, the "currently an open beta" status combined with the high-star count (428) and recent activity (last pushed 2026-10-23) suggests it may be prematurely marketed as mature. The distinction between the commercial Telekom branded version and the open-source neutral variant adds complexity but doesn't invalidate the tool itself.
- **slide-wright** — This is a thin bridge layer around GPT/LLM-based slide generation: a topic gets turned into a theme + preview, approval then regenerates the full deck. The README describes no concrete algorithm (no palette math, no layout grid, no rendering backend), no benchmark numbers, and only shows LLM text prompts as the mechanism ('Make me a slide deck about X'). The '10x'/'revolutionary' performance language is absent, so the 'hype' verdict comes from a different failure mode: the entire mechanism is unverified — we have zero evidence the output slides actually look like real presentations rather than rough LLM drafts. The project is not broken (recent last push, not archived), but as an infrastructure claim it is essentially unproven.

## Flagged as broken

- **swarmstorm** — The README gives a concrete, reproducible mechanism with a detailed phase diagram and explicit skill list, but the metadata shows a last commit date in the future (2026-10-23) and the repository is only 2 months old with few stars, indicating no real maintenance.
