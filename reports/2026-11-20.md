## New today

- ✅ **[LRC](https://github.com/zhibaiYingChuan/LRC)** (data-research) — LRC is a local memory store that saves user statements, decisions, and code, and lets AI tools query it via a CLI and sidecar, with no external server required.
- ✅ **[grommet-theme-hpe](https://github.com/grommet/grommet-theme-hpe)** (design-ux) — An npm package exporting an HPE-branded Grommet theme object (`import { hpe } from 'grommet-theme-hpe'`) plus a Storybook for visual validation of component styling.
- ✅ **[morpheus](https://github.com/aidreamy/morpheus)** (memory-context) — Morpheus is a Rust‑based terminal UI orchestrator that runs multiple AI agents simultaneously in split panes and provides computer interaction through an accessibility tree.
- ✅ **[mcplex](https://github.com/ModernOps888/mcplex)** (memory-context) — MCPlex is a single-binary Rust gateway that sits between an MCP client and multiple MCP servers, supporting both stdio (persistent child processes with a one-time initialize handshake and multiplexed JSON-RPC) and Streamable HTTP transports. It exposes the aggregated tools on a local HTTP endpoint, adds a config file (TOML), an optional dashboard/Prometheus port, and ships systemd/launchd deployment instructions.
- ⚠️ **[awesome-dsh-plugins-2026](https://github.com/Herdeny/awesome-dsh-plugins-2026)** (browser-automation) — A meticulously maintained directory that lists 346 DeepSeek Harness plugins; it is not a working tool, and its entries have not been tested or verified to run.
- ✅ **[Pseudolife-MCP](https://github.com/Pseudogiant-xr/Pseudolife-MCP)** (memory-context) — An MCP server providing persistent long-term memory for coding agents (Claude Code, Codex) with associative retrieval, canonical fact storage with version history, automated 'dream' consolidation via local or OpenAI-compatible LLMs, and a web console. Runs locally via pip install; no Docker or external database required.
