- ✅ **[ui-diff](https://github.com/imuratalpay/ui-diff)** (dev-tools) — A TypeScript CLI and agent skill that captures deterministic before/after Playwright screenshots for UI-changed routes, generates pixel diffs and a UX summary, and posts or updates a single sticky PR comment.

It exposes the aggregated tools on a local HTTP endpoint, adds a config file (TOML), an optional dashboard/Prometheus port, and ships systemd/launchd deployment instructions.

- ✅ **[Pseudolife-MCP](https://github.com/Pseudogiant-xr/Pseudolife-MCP)** (memory-context) — An MCP server providing persistent long-term memory for coding agents (Claude Code, Codex) with associative retrieval, canonical fact storage with version history, automated 'dream' consolidation via local or OpenAI-compatible LLMs, and a web console. Runs locally via pip install; no Docker or external database required.
