## Flagged as hype

- **vibe-coding-cn** — The README is explicitly self-described as "只整理已有资产，不增加业务Skill" (only organizing existing assets, not adding new skills) and repeatedly states that loading resources is not an execution license. It provides a concrete set of sub-projects (9 Context folders, Skills registry, 17 Extensions entries, prompt spreadsheet, Makefile for `make test`) and a clear entry point (`pi --skill .github/skills`), making this a real-but-narrow repo rather than broken. However, the README is essentially a curated index/handbook for a workflow the user must assemble themselves — there is no working agent binary, CI pass/fail status is unclear, and no verifiable runtime outputs are attached to the excerpt. The 17k stars and recent commit history indicate genuine traction in the niche they serve, but the repo delivers advisory content, not deployable tooling, which fits a 'hype' verdict over 'useful' or 'broken'.
- **agent-teams-ai** — The README is dominated by marketing language and screenshots with no concrete description of the agent communication mechanism or underlying architecture. Moreover, the repository timestamps (created and last pushed) are set in the future (2026), indicating fabricated activity and a lack of genuine development.
- **Pi-Bolt** — The README documents a concrete, downloadable install path (curl script, npm package, installer signing) and a reproducible build mechanism: sources.json shows the upstream Pi version used; CI is green; releases exist. But the headline differentiator ('two to three times sooner', 'one third CPU') is stated without methodology, sampling conditions, or independent verification, making it unverifiable marketing copy rather than a described mechanism.
- **trailhead** — README relies on forward-specific claims (zero external plugins, CLA-generated agents to Codex config, 24 commands, 8 hooks, specific agent names) with no mechanism to reproduce them; unverifiable performance or 10x claims absent; no independent benchmarks given. There is no concrete step-by-step runbook, list of commands, or minimum viable description. Tested only in the brief excerpt — so specific commands are not documented here.
- **dsh-defend** — 1) The README header is full of unverifiable performance claims: '1024 store channel', install ranking tied to deepseek1024.com, an animated GIF demo ('the same run'), and a claimed benchmark of 105 samples (75 positive / 30 negative) with no peer review. 2) Maintenance status is explicitly FROZEN since 2026-10-05 — a committed-statement abandonment — while only 937 weekly downloads exist; the README repeatedly claims it still works and isn't retired, which is a cover for being dead. 3) A self-critical comparison admits a rival with 13,087 downloads vs its own 937, yet frames this as proof that dsh-defend is still preferable for new work rather than evidence of irreplacability. 4) Securityscorecards badge links to an api.securityscorecards.dev endpoint that requires network access for the badge to render.
