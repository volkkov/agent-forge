- ✅ **[localpr](https://github.com/gilles-g/localpr)** (dev-tools) — A single-file Python stdlib Claude Code plugin that renders local git diffs as an offline HTML pull-request page. You comment on lines (Must fix/Follow-up/Workflow note), send batches to Claude while continuing to review, ask inline questions, and get a TODO.md back with verdicts (fixed/refused/out-of-scope/anchor-lost). No network, no repo writes, local server with token/Origin checks.
