## Flagged as hype

- **Satori** — The README's centerpiece claims — 350-case benchmark, 98.0% non-activation rate, sub-8 KB Turn-1 load, 18 wisdom traditions, 6-step reflective model — are numerical benchmarks with no cited methodology, test data, or pass/fail thresholds attached. The 'built to be outgrown' framing and the embedded dialogue example read as therapeutic-domain marketing copy dressed up as a code tool. There are no invoked dependency versions, no output format spec, no invocation examples beyond one zipped install path. A product this bare lacks the concrete reproducible mechanism required for a useful verdict.
- **prompt-engineering-in-action** — The README is overwhelmingly marketing copy: '10 days', '45% to 91%', no benchmarks, no methodology sections. The plugin install via a third-party marketplace (`/plugin marketplace add`) and a Scarf-hosted installer are repurposed from an earlier fork pattern rather than evidence of a working, reviewed tool.
