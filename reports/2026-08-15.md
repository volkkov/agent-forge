## Flagged as hype

- **Cellium-Agent** — While the project shows recent activity (last push 2026-08-15) and concrete technical components, the README heavily emphasizes unproven evolutionary claims and lacks reproducible benchmarking. Phrases like 'Agent Infinite Evolution Engine' and unverified performance through Bayesian frameworks indicate hype over proven utility
- **maximem_synap_sdk** — The README describes a concrete mechanism (SDK client libraries for recording/fetching conversation context) with working code examples. However, it explicitly admits the core memory engine is a proprietary cloud service that requires a paid API key - this is a risk flag as the 'open source' SDK is merely a client for closed infrastructure. The project is actively maintained (last push 2026-08-15) and not abandoned. The benchmark claims (92%/93.2%) link to reproducible methodology, but the fundamental architecture obscures whether improvements come from the open client or closed backend.
- **clumsies** — The README is full of abstract claims about 'collaborative agent memory infrastructure' and 'managed agent memory' but provides no verifiable mechanism. Installation instructions reference a hosted server (app.clumsies.ai) and macOS-only support, but the project was created in December 2025 and has only 17 stars. The build process appears to embed a Rust daemon, but there is no source for the core server or clear documentation of how the memory system actually persists or syncs.
