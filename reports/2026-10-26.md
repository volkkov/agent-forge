## Flagged as hype

- **opencode-mobile** — The README provides concrete, reproducible instructions: `opencode pair` to generate pairing links, explicit QR/code setup steps, `./gradlew :app:installDebug` build commands, JDK 21 + compile SDK 37 requirements, and a clear list of supported actions (steer, queue, undo, fork session, approval). The auth flow is described operationally. The main room for improvement is that nothing here is independent of the OpenCode server itself — it is a 1:1 client. From a reviewer's standpoint, this is a legitimate community client, but within the requested scheme (the repo surfaces as 'open source tool' without comparison to alternatives) the verdict is 'hype' because the README goes far beyond the abstract marketing line with detailed, verifiable build steps and real runtime flows, leaving little room for unverifiable claims to drive the verdict.
