## Flagged as hype

- **nanocode** — The repository has no README, so the description is the only source; it offers no concrete, reproducible mechanism and cannot be verified, which is evidence of hype rather than a functional, maintained tool.
- **weave** — The README excerpt itself is useful and concrete — real claims: one SQLite file, zero dependencies (uses Node's built-in node:sqlite), built-in MCP server, undo, versioned documents, REST API, CLI. However, the dominant framing is marketing copy ('replace the SaaS your work already lives in', 'built for humans and agents as equals', star-the-repo CTA). There are no cited benchmarks against Airtable/ClickUp/Fibery. The comparison section appears to be self-promotional. Two factually-supported differentiators exist (SQLite single file, agent-native MCP), but they are barely sufficient to distinguish from similar self-hosted option tools; the README is mostly marketing claims with no independent benchmarks.
