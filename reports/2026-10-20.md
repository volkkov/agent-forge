## Flagged as hype

- **claude-prompts-mcp** — The README is largely a feature table — two columns of 'what client gives' vs 'what the server adds' — plus install commands for several CLIs. No SDK signatures, no input/output contracts, no schema examples, no benchmarking, and no verification mechanism described. Per-client coverage is claimed for 8 clients but only bundled install steps are shown for most, with no hooks-specific docs beyond one experimental Codex block. 189 stars / 33 forks / active release history indicate a real project, but there is zero evidence of a reproducible mechanism beyond 'MCP server + YAML templates + plugin hooks.' That is a strong hype signal: a vendor-packaged prompt layer sold as workflow orchestration without verifiable end-to-end behaviour.
